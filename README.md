# VIVNCHA TRADELINK website

Open index.html in a browser, or upload this whole folder to any static host.

## Before launch
1. Open script.js and fill in CONFIG at the top: a WhatsApp/phone number for Nigeria, one for Cameroon, and an email.
   Until then the request form lets visitors copy their request instead of sending it.
2. Replace nothing else: all text is in index.html (English) and the FR block in script.js (French).

## Files
- index.html  structure and English text
- styles.css  design
- script.js   route chart, EN/FR switch, request form
- assets/     logo.png, mark.png
